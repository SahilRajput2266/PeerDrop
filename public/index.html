HOW IT WORKS

Peer-to-Peer Architecture Explained

PeerDrop establishes an encrypted, direct DataChannel connection between web browsers using WebRTC. Your file content never touches any cloud server or database.

01
🔗

Join the Same Room

Open PeerDrop on both devices and enter the same Room ID (or click "Share Link"). If both devices are on the same Wi-Fi, open via the Wi-Fi LAN address for Gigabit transfer speeds.

02
📡

Radar Auto-Discovery

The lightweight Node.js signaling server handles initial handshake metadata (Session Description and ICE candidate exchange). Connected peers appear instantly on the sonar radar mesh.

03
🚀

Drag, Drop & Stream

Drop any file to send. The transmission engine slices the file into 64 KB encrypted chunks, streams directly across the WebRTC tunnel, and triggers instant download on the receiver.

🔒

Zero-Knowledge Privacy

The signaling server coordinates connection setup only. File bytes flow exclusively browser-to-browser with no cloud caching or disk logging.

⚡

64 KB Chunk Slicing & Flow Control

Large files (1 GB, 4 GB+) stream smoothly using active backpressure flow control via bufferedamountlow, preventing memory overflow or channel disconnects.

📶

Local Wi-Fi / LAN Gigabit Speeds

When devices share the same Wi-Fi router or local switch, transfers bypass external internet bottlenecks and stream at full network interface line speeds.

🛡️

Hardware-Accelerated DTLS-SRTP

All WebRTC DataChannels are end-to-end encrypted by default using AES-128/256-bit DTLS, safeguarding against eavesdropping or man-in-the-middle inspection.

FAQ

Frequently Asked Questions

?

Are my files stored on any server?

Never. PeerDrop is built on a Zero-Knowledge peer-to-peer architecture. 0 KB of file content is stored on any server. File streams flow directly peer-to-peer between browsers.

?

How do I connect another phone or laptop on the same Wi-Fi?

Open the local Wi-Fi URL displayed in the top bar (e.g. http://<IP>:3003) on your other device, enter the same Room ID, and click Join.

?

How are large files (1 GB+) handled without freezing?

Files are split into 64 KB slices with WebRTC Backpressure Flow Control, monitoring buffer capacity and pacing transmission before memory or socket limits can be reached.

?

What happens when I refresh the page?

Your Room ID and Transfer History are stored in browser local storage, so refreshing the page restores your exact room and activity seamlessly.
